# Alim Launcher

Лаунчер Minecraft: Java Edition для Windows 10/11 x64. Electron + React + TypeScript. Тёмный стеклянный интерфейс на предоставленных владельцем ресурсах, бирюзовые акценты, отдельные разделы. Текущая версия: 1.0.2.

## Возможности

- Офлайн-ник и стабильный Java UUID v3, одиночная игра и совместимые офлайн-серверы. Microsoft OAuth исключён по прямой просьбе владельца. Онлайн-серверы с проверкой лицензии требуют официальный аккаунт и не поддерживаются офлайн-входом.
- Официальный манифест Mojang, релизы, снапшоты и Alpha/Beta. Загрузка клиента, assets и библиотек; проверка контрольных сумм; повторная установка восстанавливает файлы.
- Vanilla, Fabric, Forge, NeoForge, Quilt. Список загрузчиков фильтруется по Minecraft. OptiFine — ручной импорт официального установщика. Forge + OptiFine — только 1.20.1 / Forge 47.2.18 / OptiFine I6, согласно официальной таблице https://optifine.net/downloads. Неподтверждённые сочетания блокируются.
- Изолированные профили. Создание, переименование, выбор, удаление после системного подтверждения. Общие клиентские библиотеки и assets хранятся в `game/runtime`; пользовательские миры, моды и настройки — в `game/profiles/<UUID>`.
- Modrinth: поиск, выбор совместимой версии, обязательные зависимости и проверка SHA-512; установка, отключение, включение, удаление; импорт JAR/ZIP. Проверка метаданных загрузчика для импортированных модов; их зависимости требуют ручной проверки. Каталог не гарантирует отсутствие всех возможных конфликтов между сторонними модами.
- Текстурпаки и шейдерпаки: каталог и локальные файлы. Для шейдеров нужен Iris/OptiFine.
- Редактор PNG 64×64 и 64×32: кисть, ластик, заливка, пипетка, палитра, история 50 действий, второй слой, Steve/Alex, вращаемое 3D-превью, локальное сохранение, импорт/экспорт. Для применения локального скина в офлайн-Minecraft нужен соответствующий мод. Скин автоматически в игру или официальный профиль не загружается.
- Java подбирается по `javaVersion` официального JSON. При отсутствии подходящей Java скачивается runtime Mojang с проверкой SHA-1. Можно выбрать собственную Java; её major version проверяется.
- RAM, разрешение, fullscreen, лимит загрузки, светлое/тёмное оформление, язык навигации RU/EN, скрытие окна на время игры, журнал и папки.
- NSIS-установщик, GitHub Releases, проверка обновлений при запуске, ручная загрузка с прогрессом и установка при перезапуске.

## Установка и использование

Скачайте `Alim-Launcher-Setup-X.Y.Z.exe` в [Releases](https://github.com/maga17mm-hub/alim-launcher/releases). Установщик не подписан коммерческим Windows-сертификатом. Игровые файлы и Java в EXE не входят.

1. Откройте аккаунт справа сверху и сохраните офлайн-ник.
2. В «Мои сборки» создайте профиль с нужной версией/загрузчиком.
3. Для OptiFine предварительно импортируйте официальный JAR в карточке сборки.
4. Нажмите «Играть». Первая установка требует интернет; после установки можно играть без сети.
5. Моды устанавливайте для выбранной сборки. Журнал доступен внизу навигации.

Программа не предоставляет лицензию Minecraft. Используйте её с законно приобретённой копией игры и соблюдайте Minecraft EULA и лицензии модов.

## Разработка

Требования: Windows x64, Node.js 24, npm, Git. Системная Java не обязательна.

```powershell
cd D:\mylauncher
npm ci
npm run assets
npm run dev
```

```powershell
npm run typecheck
npm test
npm run build
npm run test:ui
npm run dist
```

Сборка: `dist/Alim-Launcher-Setup-1.0.0.exe` (имя зависит от `package.json`). `out` — скомпилированные файлы, `work` — изолированные тестовые профили, диагностические скриншоты и скачанный GitHub CLI. Они исключены из Git.

Для повторной интеграционной проверки настоящей установки и запуска:

```powershell
npx tsx scripts/verify-games.ts Vanilla Fabric Forge Quilt NeoForge
```

Тест скачивает игру и открывает её окна; он использует `work/acceptance`, ожидает сообщения графической инициализации и закрывает игру. Это не тест создания/прохождения мира.

## Данные и безопасность

Обычная `.minecraft` не используется. По умолчанию данные: `%APPDATA%/alim-launcher` (точное имя зависит от Electron); настройки — `state.json`, локальный скин — `skin.png`, диагностика — `logs/launcher.log`, игровые файлы — `game`.

Корень игровых файлов выбирается до создания профилей. Для переноса существующей коллекции закройте приложение, скопируйте `game` в новую папку и измените абсолютное поле `settings.root` в `state.json`, сохранив резервную копию. Папки старого корня программа сама не удаляет.

`contextIsolation`, sandbox, отключённый Node в renderer, запрет внешней навигации и окон, CSP, валидация IPC через Zod. Пароли и токены не используются. HTTPS, контрольные суммы, ограниченные имена файлов, удаление только управляемой папки профиля. Сертификаты/PAT не встраиваются в EXE.

Версии XMCL зафиксированы. Последний опубликованный `@xmcl/unzip 2.2.0` непригоден для npm (workspace-ссылка и main на отсутствующий index.ts). Используется выпущенная связка 6.1.2/2.15.1/2.1.2. Undici обновлён через override до исправленной 7.30.1; диспетчер адаптирует устаревшие параметры API XMCL. Yauzl зафиксирован на 3.4.0 для работы потоков ZIP на Node 24. Java получает отдельную папку `game/tmp`, чтобы не наследовать проблемные Windows TEMP-пути для локальных NIO-соединений. Перед сменой этих версий повторяйте настоящие установки и запуски.
